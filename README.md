# Практическая работа № 5. Симулятор планирования CPU

## Цель работы

Реализовать классические алгоритмы планирования процессов, сравнить их эффективность и исследовать влияние параметров планирования на производительность системы.

## Реализованные алгоритмы

- **FCFS (First Come, First Served)** — первым выполняется процесс, который раньше прибыл в очередь.
- **SJF (Shortest Job First)** — невытесняющее планирование с выбором процесса с наименьшим временем выполнения.
- **SRTF (Shortest Remaining Time First)** — вытесняющее планирование по наименьшему оставшемуся времени выполнения.
- **Priority Scheduling** — вытесняющее приоритетное планирование.
- **Round Robin (RR)** — циклическое планирование с заданным квантом времени.
- **Priority Scheduling with Aging** — приоритетное планирование со старением для уменьшения риска голодания процессов.

## Входные данные

Каждая строка входного файла содержит четыре поля:

`PID arrival burst priority`

- `PID` — идентификатор процесса.
- `arrival` — время прибытия процесса.
- `burst` — необходимое процессорное время.
- `priority` — приоритет процесса; меньшее число означает более высокий приоритет.

Используются три набора данных:

- **set1.txt** — контрольный набор из четырёх процессов.
- **set2.txt** — 20 процессов с продолжительным временем выполнения.
- **set3.txt** — 20 процессов с преимущественно короткими заданиями и одним длинным процессом.

## Реализованные метрики

Программа вычисляет следующие показатели:

1. **Average Waiting Time** — среднее время ожидания процессов в очереди.
2. **Average Turnaround Time** — среднее время от прибытия процесса до завершения.
3. **Average Response Time** — среднее время от прибытия до первого запуска.
4. **CPU Utilization** — процент времени, в течение которого процессор выполнял процессы.
5. **Context Switches** — количество переходов от одного процесса к другому согласно принятому в программе определению.

## Исследование Round Robin

Для набора `set2.txt` исследуется влияние кванта времени от 1 до 10 единиц на среднее время ожидания и количество переключений процессов.

График сохраняется в файл `rr_quantum.png`.

При небольшом кванте процессы получают процессор чаще, но количество переключений обычно увеличивается. При большом кванте переключений становится меньше, однако Round Robin постепенно приближается по поведению к FCFS.

## Приоритетное планирование и Aging

В работе реализовано старение приоритетов. Чем дольше процесс ожидает выполнения, тем выше становится его эффективный приоритет.

Для демонстрации используется длинный процесс с низким начальным приоритетом и поток коротких процессов с высоким приоритетом. Сравниваются результаты планирования со старением и без него.

## Проверка на контрольном наборе

Для `set1.txt` результаты сравниваются с эталонными значениями, указанными в задании.

| Алгоритм | Эталонное среднее ожидание | Эталонный средний оборот |
|---|---:|---:|
| FCFS | 9.25 | 15.75 |
| SRTF | 6.50 | 13.00 |
| RR (q = 3) | 13.50 | 20.00 |

Фактические результаты выводятся программой в терминал. Совпадение с эталоном необходимо проверить перед окончательной сдачей работы.

## Установка и запуск

Необходим Python 3 и менеджер пакетов pip.

Установка зависимостей:

```bash
py -m pip install -r requirements.txt
```

Запуск программы:

```bash
py main.py
```

После запуска программа выводит сравнительные таблицы для трёх наборов данных, проверку контрольных результатов, демонстрацию старения приоритетов и график Round Robin.

## Вывод

В ходе практической работы реализован симулятор планирования CPU с пятью классическими алгоритмами и механизмом старения приоритетов. Реализованы вычисление основных метрик производительности, сравнение алгоритмов на различных наборах процессов и исследование влияния кванта времени Round Robin на ожидание и количество переключений.

Эксперимент позволяет сравнить стратегии планирования и оценить компромисс между временем ожидания, временем отклика и частотой переключения процессов.
